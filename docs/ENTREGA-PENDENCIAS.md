# Pendências para entrega final

Este pacote é uma base funcional preparada a partir dos materiais de laboratório e do arquivo `atracoes.json`. Antes de enviar ao professor:

- [ ] Preencher instituição, data e integrantes/matrículas/contribuições no PDF.
- [ ] Revisar o código e executar localmente com um PostgreSQL real.
- [ ] Executar `npm install`, `npx prisma generate`, `npx prisma migrate dev --name init` e `npm run db:seed`.
- [ ] Testar todos os endpoints em um cliente HTTP.
- [ ] Capturar evidências reais (não são geradas automaticamente).
- [ ] Criar um repositório público no GitHub e enviar o código.
- [ ] Publicar a API e configurar `DATABASE_URL` nas variáveis de ambiente do serviço de hospedagem.
- [ ] Atualizar os links no README e no PDF.
- [ ] Registrar dificuldades e aprendizados verdadeiros da equipe.

A publicação no GitHub e no serviço de hospedagem exige acesso à conta da equipe e não foi feita por este pacote.
